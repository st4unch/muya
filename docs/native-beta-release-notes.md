Muya Native is a new, native Mac version of Muya (beta). Classic Muya 4.1.21 and later offers it once after an update check; it is also in Settings > Beta.

Installing it replaces classic Muya (classic goes to the Trash, recoverable). Your workspaces, settings, schedules and SSH servers come with you. Native has "Switch back to classic Muya" in Settings > Beta and updates itself from this channel.

Beta: expect rough edges. First launch asks you to approve Muya's background service in System Settings > Login Items; the vault's Touch ID needs one master-password unlock. Nothing is sent anywhere except the GitHub download.
